# zero-one-practice

ダーツ 501 の練習用ペライチアプリです。`index.html` をブラウザで開くだけで動作します（依存なし・ビルド不要）。

1ラウンド（3本）の合計点を数字で入力して Enter を押すと、残り点数と 1R平均（3ダーツアベレージ）が更新されます。

- ダブルアウト厳格（オーバー / 1残し / ダブルで上がれない残りからの 0 はバスト）
- 1ゲーム最大 10 ラウンド
- 直近 10 ゲームの記録を左右のサイドに表示します（通算1R平均 / 上がり数 / ベスト1R平均）。リロードすると消えます
- `Enter` 確定 / `Esc` 入力クリア / `Ctrl`(`Cmd`)+`Z` で1つ戻す
- ゲーム終了後（上がり・10R消化）は `Enter` でそのまま次のゲームが始まります
